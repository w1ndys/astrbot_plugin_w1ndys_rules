## 已经变了的行为（拆分时必须带上）

**1. 联系人卡片判定扩展**
判据加了一条 `app == "com.tencent.contact.lua"` 且 `view == "contact"`，覆盖群名片和推荐好友。原有三条规则（`prompt` 前缀「群名片」、`bizsrc == qun.share`、`meta.contact.tag == 群名片`）保留，只增不减。配置键 `forbidden_block_group_card_groups` 与日志原因码 `group_card` **没动**，兼容拆分设计。

**2. 命中后记录卡片身份**
新增 `card_identity(card)`：群名片给「群号 + 群名」，群号从头像地址的 `gh/<群号>` 段解析；推荐好友给账号（去掉「账号：」前缀）。这一行同时进违禁日志的 `text` 列（通过 `log_text` 参数）和飞书「消息」行。

**3. 日志整体改造**
- 新增 `business/hit_log.py`：命中打一行 INFO `[群管] 违禁命中 群号=… 发言人=… payload=…`，五条线路（文本模型 / 二维码 / 图片转写 / 视频抽帧 / 联系人卡片）共用，每条事件只打一行。
- 跳过类日志（管理员、白名单、未开启、越权）**全部降为 DEBUG**，不再默认刷屏。
- 前缀 `[rules]` **全仓清零**，统一改成 `[群管]`。
- payload 里的签名类字段打码后才打印（`token` / `sig` / `sign` / `secret` / `password` / `passwd` / `key` / `auth`，含字符串内嵌套 JSON 与 CQ 码形态）。

**4. 新增常量** `CARD_IDENTITY_MAX_LEN = 100`（卡片字段截断，外部输入防撑爆日志）。
