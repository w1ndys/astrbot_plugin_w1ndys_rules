# astrbot_plugin_w1ndys_rules

AstrBot 插件：群规。命中判断全部由代码完成，不调用大模型，所以不消耗 Token，
也不会因为模型发挥而回错内容。

从 monorepo `w1ndys-astrbot-plugins` 拆出，独立成仓。群开关由本插件自己管，
不抽跨插件公共模块。

## 关键词回复

- 群员发一条消息，内容与某个关键词完全相同，机器人就回预设内容。
- 不 @ 机器人、不唤醒，照样回复，也不会触发模型。
- 每个群的开关默认关闭，需要管理员执行 `kr 开` 打开（前面要带本机配置的唤醒前缀）。
- 管理员可以直接用自然语言增删改查关键词，例如「添加关键词 原神 回复 好玩」。

## 一个必须知道的坑

AstrBot 在唤醒检查阶段会把唤醒前缀从消息开头剥掉。如果某个部署把唤醒前缀配成
「卷卷」，那么群员发「卷卷你好」到最后只剩「你好」参与匹配。因此**关键词不能以
唤醒前缀开头**，否则它永远匹配不到。插件在写入时会拦下这类关键词并说明原因。

## 匹配口径

整条消息完全相等才算命中，不做包含匹配，也不放宽大小写和空白。匹配用的是
AstrBot 解析后的纯文本，不是 OneBot 原始 `raw_message`，所以带 @ 或图片的消息
只比对文本部分。

## 开发

改完插件后需要让 AstrBot 重新加载。注意 AstrBot 的热重载被环境变量守卫：

```python
if os.getenv("ASTRBOT_RELOAD", "0") == "1":
    asyncio.create_task(self._watch_plugins_changes())
```

没设 `ASTRBOT_RELOAD=1` 时文件监视根本不会启动，改代码必须重启容器才生效。
